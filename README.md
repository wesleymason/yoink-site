# Yoink website

Marketing site, privacy policy and support page for **Yoink: White Elephant Games** (iOS). Plain HTML and CSS, served by GitHub Pages from `main`.

- `index.html`: homepage
- `privacy.html`: privacy policy (App Store privacy policy URL)
- `support.html`: support and FAQ (App Store support URL)
- `assets/`: styles, fonts (Lilita One and Nunito, SIL OFL), screenshots and mascot

To use a custom domain, add it under Settings → Pages; GitHub writes the `CNAME` file.
